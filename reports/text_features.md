# Text Features — Prevalence and Validation

Generated by `python -m src.features`. Each extractor is a regex over the lowercased
`listing_title + description`. Where marked, a match is discarded if `no`, `not`, `never`,
`without`, `nothing` or a `-n't` contraction appears in the 15 characters before it.
Listings without a description (5.8%, all Autolist)
get 0 for every flag; `has_description` lets the model tell those apart.

## Patterns

| feature | pattern | negation check |
|---|---|---|
| txt_one_owner | `\b(?:one\|1\|single)[\s-]*(?:previous\s*)?(?:owner\|wner\|woner)\b\|\boriginal\s*owner\b` | yes |
| txt_clean_title | `\bclea[nr]\s*(?:\w+\s*(?:(?:&\|and)\s*)?)?title\b\|\btitle\s*(?:is\s*)?(?:clean\|clear)\b` | yes |
| txt_clean_history | `\bclean\s*(?:car-?fax\|autocheck\|history\|vehicle history)\b` | yes |
| txt_accident_free | `\b(?:no\|zero\|0)\s*(?:reported\s*\|prior\s*)?accidents?\b\|\baccident[\s-]*free\b\|\bnever\b[\w\s]{0,20}?\baccidents?\b\|\bclean\s*accident\s*history\b` | no |
| txt_service_records | `\b(?:service\|maintenance)\s*(?:records?\|history)\b\|\bdealer[\s-]*(?:maintained\|serviced)\b\|\bregularly\s*(?:maintained\|serviced)\b\|\bserviced\s*regularly\b` | yes |
| txt_new_tires | `\bnew\s*(?:set\s*of\s*)?(?:[a-z]+\s*)?tires\b\|\btires\s*(?:are\s*)?(?:brand\s*)?new\b` | yes |

## Validation against Autolist's structured history fields

Autolist rows have `owner_count` and `accident_count` from the vehicle-history report, so they
can be used as labels. Precision is the share of flagged listings where the field agrees;
recall is the share of qualifying listings that the text flags. Low recall is expected: most
dealer descriptions don't restate the history report.

| extractor | Autolist field | rows | flagged | precision | recall |
|---|---|---|---|---|---|
| txt_one_owner | owner_count == 1 | 1024 | 151 | 0.89 | 0.34 |
| txt_accident_free | accident_count == 0 | 1011 | 56 | 0.95 | 0.08 |
